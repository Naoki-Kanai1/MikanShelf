# テストケース: filterByConditions（本一覧の場所・ステータスでの絞り込み）

- ID の略号: `FC`
- PBI: #35
- 書いた人: satogorou
- もとにした資料: [画面設計書](../../docs/ap/BookListPage/Screen_design.md)（3章「場所・ステータスでの絞り込み」）

本一覧画面で、場所（チェックボックス。いくつでも）とステータス（ラジオボタン。「すべて」か「借りられる」）で本を絞り込む。
狭い画面（〜599px）では検索ボックスの右端のボタンで開くモーダルで、広い画面（600px〜）では検索ボックスの下に直接並べた選択肢で選ぶ。
検索の文字を入れているときは、条件と部分一致の両方に合う本を出す。場所の選択肢は本の一覧（`GET /api/books`）から作る。
画面のテストでは、API の応答を作り物に差し替える。jsdom では CSS の `@media` で隠さないので、ボタン（モーダル）と直接並べた選択肢の両方を確かめられる。

欠番（決まりを変えて消したケース。ID は使い回さない）:
FC-09（状態を2つ選ぶ）、FC-19・FC-20（状態を選ぶ・外す）、FC-23・FC-24（置き場所の API）、FC-27・FC-28（モーダルで置き場所を読み込み中・読み込めない）、
FC-34・FC-39・FC-43（モーダルを開いたときに置き場所の API を呼ぶ）、FC-45・FC-51・FC-52（条件に合う冊と同じ置き場所の冊を全て出す）、FC-55（状態を2つ選ぶ）、
FC-85〜FC-87（置き場所の全ての冊を数える `makeCopyCounter`）、FC-89（状態で絞っても「／m冊」は全ての冊で数える）、
FC-56〜FC-61（絞り込む前の全ての冊で残りを数える `makeOnShelfCounter`）、FC-62・FC-90（状態で絞っても「残りn冊」は実際の数）、
FC-01〜FC-04（3つの状態を返す `bookFilterStatusOf`）、FC-08・FC-64・FC-10・FC-36・FC-46・FC-50・FC-54・FC-69・FC-71・FC-76・FC-81・FC-83・FC-91・FC-92（状態「誰かが借用中」「持ち出し禁止」で絞る。選択肢から消した）
