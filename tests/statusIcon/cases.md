# テストケース: statusIcon（状態の欄のアイコンを開いた本にする）

- ID の略号: `SI`
- PBI: #30
- 書いた人: oinuma-kano

本詳細画面と貸出詳細画面の「状態」の欄の左のアイコンを、開いた本のアイコンにそろえた。

- 本詳細: 四角に横線の本のアイコン → 開いた本のアイコン
- 貸出詳細: 矢印2本のアイコン → 開いた本のアイコン

開いた本のアイコンは、左右2枚のページの線（`<path>` 2本）でできている。テストでは、「状態」の欄のアイコンの
`<path>` の `d` が開いた本の形と同じかで確かめる。API の応答はテストの中で作り物に差し替える。
線の太さ・色などの見た目は jsdom では確かめられないため、ブラウザで別に確かめる。

## BookDetail（`frontend/src/BookDetail.tsx`）

本詳細画面の「状態」の欄のアイコン。

| ID    | 観点 | 条件・入力                               | 期待する結果                                                        |
| ----- | ---- | ---------------------------------------- | ------------------------------------------------------------------- |
| SI-01 | 正常 | 棚にある本を開く                         | 「状態」の欄のアイコンが開いた本の形（左右のページの `<path>` 2本） |
| SI-02 | 正常 | 棚にある本を開く                         | 前の四角に横線の本のアイコン（`<rect>`）は出さない                  |
| SI-03 | 状態 | 誰かが借用中の本／持ち出し禁止の本を開く | 本の状態によらず、同じ開いた本のアイコンを出す                      |
