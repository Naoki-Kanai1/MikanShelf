# テストケース: borrowablePriority（同じ本が何冊もあるとき、開く本を状態で選ぶ）

- ID の略号: `BP`
- PBI: 本詳細画面に遷移する際、持ち出し禁止と棚にある本が共存する時、棚にある本の詳細画面を優先的に表示させる（Sprint2）
- 書いた人: aoki-satoshi

同じ本が何冊もあるとき、代表の1冊（行を押したときに開く本）を、ID の順ではなく状態の順で選ぶ。
状態の優先順は「棚にある（借りられる）→ 持ち出し禁止 → 誰かが借用中」。同じ順位の本が何冊もあれば、もとの順で最初の1冊。
画面のテストでは、API（`GET /api/books`）の応答を作り物に差し替える。

## BookListPage の状態の印（`frontend/src/pages/BookListPage.tsx`）

行の状態の印は、開く本（代表）の状態を出す。棚にある（借りられる）本が1冊でもあれば「借りられる」、無ければ持ち出し禁止の本があれば「持ち出し禁止」、全て貸出中のときだけ「誰かが借用中」。
