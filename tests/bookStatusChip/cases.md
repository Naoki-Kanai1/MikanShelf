# テストケース: bookStatusChip（本の状態の印の見直し）

- ID の略号: `SC`
- PBI: #27（ステータスの表示を見直す）
- 書いた人: satogorou

本の状態の印（棚にある／誰かが借用中／持ち出し禁止）について、次を見直した。

- 本詳細画面でも、持ち出し禁止の本は「棚にある」ではなく「持ち出し禁止」を出す
- 「貸出中」は借りられるのかと誤解されやすいので、ほかの人が借りていると分かる「誰かが借用中」にする
- 3つの印の大きさを、いちばん大きい「持ち出し禁止」にそろえる（`.status-chip` の最小の幅）
- 「誰かが借用中」の枠を消し、ボタンと間違われないようにする

API（`GET /api/books/:id`）の応答は、テストの中で作り物に差し替える（本物のサーバーと DB は使わない）。
大きさ・枠・色などの見た目は jsdom では CSS が効かないため、ブラウザで別に確かめる。
