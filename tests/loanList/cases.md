- ID の略号: `LL`
- PBI: #27（ヘッダーの画面の名前と、絞り込みのチップの名前をフッターに合わせる）
- 書いた人: Kano Oinuma
- もとにした資料: [画面設計書](../../docs/ap/LoanListPage/Screen_design.md)

API（`GET /api/loans`）の応答は、テストの中で作り物に差し替える（本物のサーバーと DB は使わない）。

## LoanListPage（`frontend/src/pages/LoanListPage.tsx`）

ログイン中の人の貸出を API から読み込み、絞り込みのチップで「いま借りている本／返却済みの本／すべて」を切り替えて並べる。

| ID    | 観点 | 条件・入力                                             | 期待する結果                                                                                                    |
| ----- | ---- | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| LL-01 | 正常 | 画面を開く                                             | `GET /api/loans` を1回だけ呼ぶ                                                                                  |
| LL-02 | 正常 | 画面を開く                                             | 画面の名前「借りている本」を見出しとして表示する                                                                |
| LL-03 | 正常 | 画面を開く                                             | 絞り込みのチップ「いま借りている本」「返却済みの本」「すべて」をこの順に表示する。古い名前は表示しない          |
| LL-04 | 状態 | 画面を開いた直後                                       | 「いま借りている本」だけが選ばれた状態（`aria-pressed="true"`）になる                                           |
| LL-05 | 状態 | API の応答がまだ返ってこない                           | 「読み込み中…」と、画面の名前「借りている本」を表示する。一覧は表示しない                                      |
| LL-06 | 状態 | 貸出中1件・返却済み1件を返し、初めの状態のまま         | 貸出中の本だけを表示する                                                                                        |
| LL-07 | 状態 | LL-06 と同じ応答で、「返却済みの本」を押す             | 返却済みの本だけを表示し、「返却済みの本」だけが選ばれた状態になる                                              |
| LL-08 | 状態 | LL-06 と同じ応答で、「すべて」を押す                   | 2件とも表示し、「すべて」だけが選ばれた状態になる                                                              |
| LL-09 | 正常 | API が貸出（id: 5）を返す                              | 行のリンク先が `/loans/5` で、題名と「借りた日 YYYY年M月D日」（日本時間）を表示する                            |
| LL-10 | 境界 | 返却済みだけを返し、初めの状態のまま                   | 「いま借りている本はありません。」を表示する。一覧は表示しない                                                  |
| LL-11 | 境界 | 貸出中だけを返し、「返却済みの本」を押す               | 「返却済みの本はまだありません。」を表示する                                                                    |
| LL-12 | 境界 | 空の一覧（0件）を返し、「すべて」を押す                | 「借りた本はまだありません。」を表示する                                                                        |
| LL-13 | 異常 | API がエラー（HTTP 500）を返す                         | 「貸出の一覧を読み込めませんでした。…」を alert として、画面の名前「借りている本」と表示する。一覧は表示しない |
| LL-14 | 異常 | 通信に失敗する（fetch が例外を投げる）                 | LL-13 と同じエラーの文を表示する                                                                                |
