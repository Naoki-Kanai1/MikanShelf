## filterBooks（`frontend/src/utils/filterBooks.ts`）

題名か著者に、入力した文字を含む本だけを、もとの順のまま返す（部分一致）。
空白は入力・本の側とも無視する。著者は「、」で区切って1人ずつ比べ、区切りの「、」は探す対象に含めない。

| ID    | 観点 | 条件・入力                                                                              | 期待する結果                                                  |
| ----- | ---- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| SB-01 | 正常 | 題名の一部（「プログラマー」）                                                          | 題名にその文字を含む本だけを返す                              |
| SB-02 | 正常 | 著者の一部（「Hunt」）                                                                  | 著者にその文字を含む本だけを返す                              |
| SB-03 | 正常 | 複数の著者（「、」区切り）のうち2人目の名前の一部                                       | その本を返す                                                  |
| SB-04 | 正常 | 題名に含む本と、著者に含む本が両方ある                                                  | 両方を、もとの順のまま返す                                    |
| SB-05 | 正常 | 英字の大文字・小文字が違う（「readable」で「Readable」）                                | 区別せずに返す                                                |
| SB-06 | 正常 | 全角・半角が違う（「ＵＩ」で「UI」、「ﾃｽﾄ」で「テスト」）                               | 区別せずに返す                                                |
| SB-07 | 境界 | 空の文字                                                                                | 全ての本を、もとの順のまま返す                                |
| SB-08 | 境界 | 空白だけ（半角・全角の空白）                                                            | 全ての本を返す                                                |
| SB-09 | 境界 | 前後に空白がある（「 達人 」）                                                          | 空白を無視して絞り込む                                        |
| SB-10 | 境界 | 題名の全体と同じ文字                                                                    | その本を返す                                                  |
| SB-11 | 境界 | どの本にも含まれない文字                                                                | 空の一覧を返す                                                |
| SB-12 | 境界 | 本が0冊                                                                                 | 空の一覧を返す                                                |
| SB-13 | 正常 | 絞り込んだあと                                                                          | もとの一覧（引数の配列）は変わらない。返すのは別の配列        |
| SB-14 | 境界 | 正規表現で特別な意味を持つ記号（「C++」「.」）                                          | 記号を文字のまま探す（「.」はどの文字にも合う、とはならない） |
| SB-22 | 正常 | 姓と名の間に空白がある著者（「Dustin Boswell」）を、空白なし（「DustinBoswell」）で探す | その本を返す                                                  |
| SB-23 | 正常 | 空白の無い著者（「山田太郎」）を、空白あり（「山田 太郎」「山田　太郎」）で探す         | その本を返す                                                  |
| SB-24 | 正常 | 姓と名の間に空白がある著者を、空白ありで探す（半角・全角・空白の数の違い）              | どれもその本を返す                                            |
| SB-25 | 正常 | 題名の空白も無視する（「Readable Tests」を「ReadableTests」で探す）                     | その本を返す                                                  |
| SB-26 | 境界 | 2人の著者の名前をまたぐ文字（「Boswell、Trevor」「BoswellTrevor」）                     | どの本も返さない（著者は1人ずつ比べる）                       |
| SB-27 | 境界 | 「、」だけで探す                                                                        | 著者が複数いるだけの本は返さない。題名に「、」を含む本は返す  |
| SB-28 | 正常 | 半角の区切り「､」で書かれた著者                                                         | 全角の「、」と同じく区切りとして扱う（SB-26 と同じ結果）      |

## groupBooks（`frontend/src/utils/groupBooks.ts`）

題名と著者がどちらも同じ本を1つのまとまりにし、代表の1冊を決める。

| ID    | 観点 | 条件・入力                                       | 期待する結果                         |
| ----- | ---- | ------------------------------------------------ | ------------------------------------ |
| SB-29 | 正常 | 同じ題名・著者の本が3冊（間に別の本がはさまる）  | 1つのまとまりに3冊が、もとの順で入る |
| SB-30 | 正常 | 題名が同じで著者が違う本                         | 別々のまとまりになる                 |
| SB-31 | 正常 | 著者が同じで題名が違う本                         | 別々のまとまりになる                 |
| SB-32 | 正常 | まとまりの並び                                   | それぞれの最初の1冊が出てくる順      |
| SB-33 | 状態 | まとまりの中に棚にある本と貸出中の本がある       | 代表は、棚にある本のうち最初の1冊    |
| SB-34 | 状態 | まとまりの本が全て貸出中                         | 代表は、最初の1冊                    |
| SB-35 | 境界 | 1冊だけの本                                      | 1冊のまとまりになり、代表はその本    |
| SB-36 | 境界 | 本が0冊                                          | 空の一覧を返す                       |
| SB-37 | 境界 | 空白・全角半角・大文字小文字だけが違う題名・著者 | 同じ本として1つにまとめる            |

## groupByLocation（`frontend/src/utils/groupBooks.ts`）

同じ本のまとまりを開いたときの行を作る。置き場所が全く同じ本を1つにまとめ、棚にある冊数を数える。

| ID    | 観点 | 条件・入力                                                     | 期待する結果                                                                           |
| ----- | ---- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| SB-47 | 正常 | 同じ置き場所の本が2冊と、別の置き場所の本が1冊（間にはさまる） | 2つにまとめ、置き場所ごとの本をもとの順で入れる。並びは置き場所の最初の1冊が出てくる順 |
| SB-48 | 状態 | 同じ置き場所に貸出中1冊・棚にある2冊                           | 棚にある冊数は 2。代表は棚にある本のうち最初の1冊                                      |
| SB-49 | 状態 | 同じ置き場所の本が全て貸出中                                   | 棚にある冊数は 0。代表は最初の1冊                                                      |
| SB-50 | 境界 | 置き場所の文字が少しでも違う（「3階 書架A」と「3階書架A」）    | 別々にする（全く同じときだけまとめる）                                                 |

## BookListPage の同じ本のまとまり（`frontend/src/pages/BookListPage.tsx`）

同じ題名・著者の本が何冊もあるときは、代表の1冊と冊数を1行に出し、押すと1冊ずつの行を開く・閉じる。

| ID    | 観点 | 条件・入力                                                           | 期待する結果                                                                                                                      |
| ----- | ---- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| SB-39 | 正常 | 同じ題名・著者の本が3冊ある                                          | 1行だけ表示し、「3冊」を出す。閉じた状態（`aria-expanded` が `false`）で、1冊ずつの行は表示しない                                 |
| SB-40 | 正常 | まとまりの行を押す                                                   | 開いた状態（`aria-expanded` が `true`）になり、置き場所の違う3冊それぞれの置き場所・状態の印を行ごとに表示する                    |
| SB-41 | 正常 | 開いた1冊の行                                                        | リンク先がその本の本詳細画面（`/books/:id`）。押すと移動する                                                                      |
| SB-42 | 状態 | 開いたまとまりの行をもう一度押す                                     | 閉じて、1冊ずつの行を表示しない                                                                                                   |
| SB-43 | 状態 | 棚にある本と貸出中の本が混ざる／全て貸出中                           | まとまりの行の印は、それぞれ「棚にある」／「貸出中」                                                                              |
| SB-44 | 状態 | 全て持ち出し禁止／一部だけ持ち出し禁止（持ち出し禁止の本は棚にある） | まとまりの行で、状態の印の代わりに「持ち出し禁止」を出すのは、全て持ち出し禁止のときだけ。開いた行には置き場所ごとに出す（SB-56） |
| SB-45 | 境界 | 1冊だけの本                                                          | これまでどおりリンクの行で表示し、冊数も開く・閉じるボタンも出さない                                                              |
| SB-46 | 正常 | まとまりの本を題名で絞り込む                                         | まとまりのまま1行で表示する（冊数も同じ）                                                                                         |

## BookListPage の置き場所ごとの行（`frontend/src/pages/BookListPage.tsx`）

同じ本のまとまりを開いたとき、置き場所が全く同じ本は1行にまとめ、状態の印の右に「残りn冊」（n は棚にある冊数。0 のときも出す）を出す。

| ID    | 観点 | 条件・入力                                               | 期待する結果                                                                      |
| ----- | ---- | -------------------------------------------------------- | --------------------------------------------------------------------------------- |
| SB-52 | 正常 | 同じ置き場所に3冊（貸出中1冊・棚にある2冊）              | 1行にまとめ、「棚にある」と「残り2冊」を出す。リンク先は棚にある本のうち最初の1冊 |
| SB-53 | 状態 | 同じ置き場所の本が全て貸出中                             | 1行にまとめ、「貸出中」と「残り0冊」を出す。リンク先は最初の1冊                   |
| SB-54 | 境界 | 置き場所に1冊だけ（棚にある）                            | 「棚にある」と「残り1冊」を出す。リンク先はその本                                 |
| SB-55 | 正常 | 「残りn冊」のある行を押す                                | 開く・閉じるにはならず（ボタンでなくリンク）、棚にある本の本詳細画面へ移動する    |
| SB-56 | 状態 | 同じ置き場所の本が全て持ち出し禁止／一部だけ持ち出し禁止 | 「持ち出し禁止」を出すのは、全て持ち出し禁止のときだけ                            |
| SB-57 | 境界 | 置き場所に1冊だけ（貸出中）                              | 「貸出中」と「残り0冊」を出す                                                     |
