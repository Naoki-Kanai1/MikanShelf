## formatDate（`frontend/src/utils/formatDate.ts`）

SQLite の `datetime('now')` が返す UTC の日時（`YYYY-MM-DD HH:MM:SS`）を、日本時間の「2026年11月2日」の形にする。

| ID    | 観点 | 条件・入力                                              | 期待する結果                   |
| ----- | ---- | ------------------------------------------------------- | ------------------------------ |
| FD-01 | 正常 | `2026-11-02 03:00:00`                                   | `2026年11月2日`                |
| FD-02 | 境界 | `2026-11-01 15:00:00`（日本時間では翌日の 0:00）        | `2026年11月2日`                |
| FD-03 | 境界 | `2026-12-31 15:00:00`（日本時間では翌年の 1月1日 0:00） | `2027年1月1日`                 |
| FD-04 | 正常 | `2026-01-05 00:00:00`（月と日が1桁）                    | `2026年1月5日`（0 を付けない） |
| FD-05 | 異常 | `不明`（日時として読めない文字）                        | `不明`（そのまま返す）         |
| FD-06 | 異常 | 空の文字                                                | 空の文字（そのまま返す）       |
