# テストケース: bookStock（本詳細・貸出詳細の「棚にある冊数」）

- ID の略号: `BS`
- PBI: #23
- 書いた人: kanai-naoki

本詳細画面と貸出詳細画面の「状態」の下に、同じ題名の本のうち棚にある（貸出中でない）冊数を「棚にある冊数」として表示する。
画面のテストでは、API（`GET /api/books/:id`、`GET /api/loans/:id`、`POST /api/loans/:id/return`）の応答を作り物に差し替える。

## countBooksOnShelf（`backend/src/bookStock.ts`）

同じ題名の本のうち、`loans` に貸出中（`borrowed`）の行がない本の冊数を返す。テストはメモリ上の DB を使い、テスト専用の題名の本を入れて確かめる。

| ID    | 観点 | 条件・入力                                                       | 期待する結果                            |
| ----- | ---- | ---------------------------------------------------------------- | --------------------------------------- |
| BS-01 | 正常 | その題名の本が1冊あり、貸出がない                                | 1                                       |
| BS-02 | 状態 | その題名の本が3冊あり、1冊が貸出中                               | 2                                       |
| BS-03 | 状態 | その題名の本が2冊あり、2冊とも貸出中                             | 0                                       |
| BS-04 | 状態 | その題名の本が1冊あり、返却済みの貸出だけがある                  | 1（返却済みの本は棚にあるとして数える） |
| BS-05 | 正常 | その題名の本が2冊あり、1冊が持ち出し禁止（`is_restricted = 1`）  | 2（持ち出し禁止の本も数える）           |
| BS-06 | 境界 | その題名の本が DB にない                                         | 0                                       |
| BS-07 | 境界 | 題名の前後に文字が付いた本・英字の大文字小文字だけが違う本がある | 題名が完全に同じ本だけを数える          |
| BS-08 | 境界 | 空の文字（`''`）                                                 | 0                                       |

## BookDetail（`frontend/src/BookDetail.tsx`）

本詳細画面。API の `on_shelf_count` を「棚にある冊数」として表示する。

| ID    | 観点 | 条件・入力                          | 期待する結果                                                         |
| ----- | ---- | ----------------------------------- | -------------------------------------------------------------------- |
| BS-09 | 正常 | `on_shelf_count` が 2               | 見出し「棚にある冊数」と「2冊」を表示する                            |
| BS-10 | 境界 | `on_shelf_count` が 0（全部貸出中） | 「0冊」を表示する                                                    |
| BS-11 | 正常 | 画面を開く                          | 項目の並びが「置き場所」「状態」「棚にある冊数」「いま借りている人」 |

## LoanDetail（`frontend/src/LoanDetail.tsx`）

貸出詳細画面。API の `on_shelf_count` を「棚にある冊数」として表示する。

| ID    | 観点 | 条件・入力                                                                  | 期待する結果                                                   |
| ----- | ---- | --------------------------------------------------------------------------- | -------------------------------------------------------------- |
| BS-12 | 正常 | `on_shelf_count` が 3                                                       | 見出し「棚にある冊数」と「3冊」を表示する                      |
| BS-13 | 境界 | `on_shelf_count` が 0                                                       | 「0冊」を表示する                                              |
| BS-14 | 正常 | 貸出中の貸出を開く                                                          | 項目の並びが「借りた場所」「状態」「棚にある冊数」「借りた日」 |
| BS-15 | 状態 | 貸出中（0冊）の本を「返す」、返却の応答は 1冊。完了ダイアログの「OK」を押す | OK を押すまでは「0冊」のまま、押すと「1冊」に変わる            |
