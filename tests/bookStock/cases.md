# テストケース: bookStock（本詳細の「この棚にある冊数」・貸出詳細の「全フロアの残り冊数」）

- ID の略号: `BS`
- PBI: #23
- 書いた人: kanai-naoki

本詳細画面と貸出詳細画面の「状態」の下に、同じ題名の本のうち棚にある（貸出中でない）冊数を表示する。
見出しは、本詳細画面が「この棚にある冊数」、貸出詳細画面が「全フロアの残り冊数」。本詳細画面は、その本と置き場所も同じ本だけを数える（PBI #25 で変更）。貸出詳細画面は、全ての置き場所の本を数える。
画面のテストでは、API（`GET /api/books/:id`、`GET /api/loans/:id`、`POST /api/loans/:id/return`）の応答を作り物に差し替える。

## countBooksOnShelf（`backend/src/bookStock.ts`）

同じ題名の本のうち、`loans` に貸出中（`borrowed`）の行がない本の冊数を返す。テストはメモリ上の DB を使い、テスト専用の題名の本を入れて確かめる。

| ID    | 観点 | 条件・入力                                                       | 期待する結果                            |
| ----- | ---- | ---------------------------------------------------------------- | --------------------------------------- |
| BS-01 | 正常 | その題名の本が1冊あり、貸出がない                                | 1                                       |
| BS-02 | 状態 | その題名の本が3冊あり、1冊が貸出中                               | 2                                       |
| BS-03 | 状態 | その題名の本が2冊あり、2冊とも貸出中                             | 0                                       |
| BS-04 | 状態 | その題名の本が1冊あり、返却済みの貸出だけがある                  | 1（返却済みの本は棚にあるとして数える） |
| BS-05 | 正常 | その題名の本が2冊あり、1冊が持ち出し禁止（`is_restricted = 1`）  | 2（持ち出し禁止の本も数える）           |
| BS-06 | 境界 | その題名の本が DB にない                                         | 0                                       |
| BS-07 | 境界 | 題名の前後に文字が付いた本・英字の大文字小文字だけが違う本がある | 題名が完全に同じ本だけを数える          |
| BS-08 | 境界 | 空の文字（`''`）                                                 | 0                                       |

## countBooksOnShelfAtLocation（`backend/src/bookStock.ts`）

同じ題名で、置き場所も同じ本のうち、`loans` に貸出中（`borrowed`）の行がない本の冊数を返す（本詳細で使う）。PBI #25 で追加。

| ID    | 観点 | 条件・入力                                                                                | 期待する結果                             |
| ----- | ---- | ----------------------------------------------------------------------------------------- | ---------------------------------------- |
| BS-16 | 正常 | 同じ題名の本が、置き場所 A に2冊・置き場所 B に1冊（貸出なし）                            | A を指定すると 2、B を指定すると 1       |
| BS-17 | 状態 | 置き場所 A の2冊のうち1冊が貸出中。置き場所 B に1冊                                       | A は 1（ほかの置き場所の本は数えない）   |
| BS-18 | 状態 | 置き場所 A の本が全て貸出中で、置き場所 B には棚にある本がある                            | A は 0                                   |
| BS-19 | 正常 | 置き場所 A に、持ち出し禁止の本と、返却済みの貸出だけがある本                             | 2（どちらも棚にあるとして数える）        |
| BS-20 | 境界 | 置き場所 A に、同じ題名の本がない（ほかの置き場所にはある）                               | 0                                        |
| BS-21 | 境界 | 置き場所の文字が少しでも違う本（「書架A」と「書架 A」）、題名が違う本が同じ置き場所にある | 題名も置き場所も完全に同じ本だけを数える |
