# テストケース: loanListFilterPosition（貸出一覧の絞り込みのタブを、画面の名前の下に置く）

- ID の略号: `FP`
- PBI: #40
- 書いた人: Kano Oinuma
- もとにした資料: [画面設計書](../../docs/ap/LoanListPage/Screen_design.md)

絞り込みのタブ（いま借りている本／返却済みの本／すべて）は、どの画面の幅でも画面の名前「借りている本」の下に置く。
これまでは幅 840px 以上のときだけ、CSS（`LoanListPage.css` の `@media (min-width: 840px)`）でタブを画面の名前の横に並べていた。
テストの画面（jsdom）は CSS の幅による切り替えをしないため、次の2つを確かめる。

- 画面の部品の並び順（画面の名前のすぐ後ろにタブがある）
- CSS の 840px 以上の指定に、画面の名前とタブを横に並べる指定が残っていない

API（`GET /api/loans`）の応答は、テストの中で作り物に差し替える（本物のサーバーと DB は使わない）。

## LoanListPage（`frontend/src/pages/LoanListPage.tsx`）

| ID    | 観点 | 条件・入力                     | 期待する結果                                                                     |
| ----- | ---- | ------------------------------ | -------------------------------------------------------------------------------- |
| FP-01 | 正常 | 画面を開く                     | 画面の名前「借りている本」の帯のすぐ後ろ（下）に、絞り込みのタブのまとまりがある |
| FP-02 | 正常 | 貸出1件を返す                  | 上から「画面の名前」「絞り込みのタブ」「一覧」の順に並ぶ                         |
| FP-03 | 状態 | API の応答がまだ返ってこない   | 画面の名前のすぐ後ろにタブがあり、その後ろに「読み込み中…」がある                |
| FP-04 | 状態 | API がエラー（HTTP 500）を返す | 画面の名前のすぐ後ろにタブがあり、その後ろにエラーの文がある                     |
