# テストケース: bookList（本一覧画面）

- ID の略号: `BL`
- PBI: #20（単体テストの見本。画面の部品のテストの例）
- 書いた人: Sho Nakata
- もとにした資料: [画面設計書](../../docs/ap/BookListPage/Screen_design.md)

API（`GET /api/books`）の応答は、テストの中で作り物に差し替える（本物のサーバーと DB は使わない）。
バックエンドの `GET /api/books` の処理は、関数に分けてから別にテストする。

## BookListPage（`frontend/src/pages/BookListPage.tsx`）

本の一覧を API から読み込み、題名・著者・状態の印・持ち出し禁止を並べる。

| ID    | 観点 | 条件・入力                                                        | 期待する結果                                                                                       |
| ----- | ---- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| BL-01 | 正常 | 画面を開く                                                        | `GET /api/books` を1回だけ呼ぶ                                                                     |
| BL-02 | 状態 | API の応答がまだ返ってこない                                      | 「読み込み中…」と、画面の名前「本一覧」を表示する。一覧は表示しない                                    |
| BL-03 | 正常 | API が本を3冊返す                                                 | 3冊の題名と著者を、API が返した順に表示する                                                        |
| BL-04 | 正常 | API が本（id: 1, 7）を返す                                        | 各行のリンク先が `/books/1`、`/books/7` になる                                                     |
| BL-05 | 正常 | 本の行を押す                                                      | その本の本詳細画面（`/books/:bookId`）へ移動する                                                   |
| BL-06 | 状態 | `status` が `available` の本と `borrowed` の本                    | それぞれの行に「棚にある」「貸出中」を表示する                                                     |
| BL-07 | 状態 | `is_restricted` が `1` の本と `0` の本                            | `1` の本の行にだけ「持ち出し禁止」を表示する                                                       |
| BL-08 | 境界 | API が空の一覧（0冊）を返す                                       | 「登録されている本はまだありません。」と、画面の名前「本一覧」を表示する。一覧は表示しない             |
| BL-09 | 異常 | API がエラー（HTTP 500）を返す                                    | 「本の一覧を読み込めませんでした。…」を alert として、画面の名前「本一覧」と表示する。一覧は表示しない |
| BL-10 | 異常 | 通信に失敗する（fetch が例外を投げる）                            | BL-09 と同じエラーの文を表示する                                                                   |
| BL-11 | 境界 | 題名と著者がとても長い（200文字）、著者が複数（「、」区切り）の本 | 題名と著者を省略せずにそのまま表示する                                                             |

## StatusChip（`frontend/src/components/StatusChip.tsx`）

本の貸出状態の印（棚にある／貸出中）。本一覧・本詳細で共通に使う。

| ID    | 観点 | 条件・入力                            | 期待する結果                                                                 |
| ----- | ---- | ------------------------------------- | ---------------------------------------------------------------------------- |
| BL-12 | 正常 | `status="available"`                  | 「棚にある」を表示し、クラス `status-chip--available` が付く                 |
| BL-13 | 正常 | `status="borrowed"`                   | 「貸出中」を表示し、クラス `status-chip--borrowed` が付く                    |
| BL-14 | 正常 | `className="book-row__status"` を渡す | もとのクラスに加えて `book-row__status` が付く                               |
| BL-15 | 境界 | `className` を渡さない                | クラスは `status-chip status-chip--available` だけ（末尾に余分な空白がない） |
| BL-16 | 正常 | どちらの状態でも                      | 色だけでなく、印（アイコン）が付く（`svg` が1つある）                        |
