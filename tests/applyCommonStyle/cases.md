# テストケース: applyCommonStyle（詳細画面に共通のスタイルを使う）

- ID の略号: `CS`
- PBI: #38
- 書いた人: kanai-naoki

本詳細・貸出詳細画面と完了ダイアログが、共通の色（`styles/theme.css`）・アイコン（`components/icons.tsx`）・
読み込み中やエラーの文（`styles/PageMessage.css` の `.page-message`）を使うようにした変更のテスト。
きっかけは、貸出詳細画面で「返却済み」の印の文字が薄くて読めなかったこと（詳細画面だけが `--color-outline` を区切り線用の薄い色で上書きしていた）。

API の応答はテストの中で作り物に差し替える（本物のサーバーと DB は使わない）。

色・文字の大きさ・フォーカスの印など CSS の見た目は jsdom では確かめられない。そこで、起動したアプリをブラウザ（Chromium、幅 375px・1280px）で開いて、次のことを確かめた。

- 貸出詳細（返却済み）の「返却済み」の文字の色が `rgb(131, 116, 105)`（= `#837469`）で、一覧画面と同じ。
- 区切り線・ボタン・案内の色が、前とほぼ同じ。
- Tab キーで戻るボタンを選ぶと、`outline: solid` の印が出る。
