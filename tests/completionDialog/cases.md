# テストケース: completionDialog（借りた・返したあとの完了ダイアログ）

- ID の略号: `CP`
- PBI: #22
- 書いた人: satogorou

借りる・返すの前の確認ダイアログをやめ、借りた・返したあとに完了ダイアログ（メッセージ・緑のチェックマーク・OK ボタン）を出すようにした変更のテスト。
API（`POST /api/books/:id/borrow`、`POST /api/loans/:id/return` など）の応答は、テストの中で作り物に差し替える（本物のサーバーと DB は使わない）。

テストの環境（jsdom）には `<dialog>` の `showModal()`・`close()` と `<form method="dialog">` の動きがないため、
`frontend/src/test/dialogPolyfill.ts` で同じ動き（開く・閉じる・閉じたら `close` イベントを出す）をする代わりのものを入れている。
Esc キーで閉じる操作も jsdom では起こせないため、ブラウザーが Esc で行うのと同じ `close()` を呼んで確かめる。

## CompletionDialog（`frontend/src/components/CompletionDialog.tsx`）

借りた・返したことを知らせ、OK で閉じるダイアログ。

| ID    | 観点 | 条件・入力                              | 期待する結果                                                      |
| ----- | ---- | --------------------------------------- | ----------------------------------------------------------------- |
| CP-01 | 正常 | `message="本を借りました！"` で開く     | メッセージ、チェックマークのアイコン、「OK」ボタンを表示する      |
| CP-02 | 状態 | 開く前                                  | ダイアログは閉じている（`open` が false）。`onClose` は呼ばれない |
| CP-03 | 正常 | 開いて「OK」を押す                      | ダイアログが閉じ、`onClose` が1回呼ばれる                         |
| CP-04 | 正常 | 開いて、OK を押さずに閉じる（Esc キー） | ダイアログが閉じ、`onClose` が1回呼ばれる                         |

## BookDetail の借りる（`frontend/src/BookDetail.tsx`）

「借りる」を押すと確認なしで借り、借りたら完了ダイアログを出す。OK で貸出の詳細画面へ移動する。

| ID    | 観点 | 条件・入力                                    | 期待する結果                                                                                     |
| ----- | ---- | --------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| CP-05 | 正常 | 棚にある本（id: 1）で「借りる」を押す         | 確認ダイアログ（「この本を借りますか？」）は出さず、すぐに `POST /api/books/1/borrow` を1回呼ぶ  |
| CP-06 | 正常 | 借りる API が貸出（id: 9）を返す              | 「本を借りました！」のダイアログが開く。OK を押すまでは本の詳細画面のまま                        |
| CP-07 | 正常 | CP-06 のあと「OK」を押す                      | 貸出の詳細画面（`/loans/9`）へ移動する                                                           |
| CP-08 | 正常 | CP-06 のあと、OK を押さずに閉じる（Esc キー） | 貸出の詳細画面（`/loans/9`）へ移動する                                                           |
| CP-09 | 異常 | 借りる API が 409（すでに貸出中）を返す       | 完了ダイアログは開かず、「この本はすでに貸出中です」を表示する。画面は移動しない                 |
| CP-10 | 異常 | 借りる API が 403（持ち出し禁止）を返す       | 完了ダイアログは開かず、「この本は持ち出し禁止のため貸出できません」を表示する。画面は移動しない |
| CP-11 | 異常 | 借りる API が 500 を返す                      | 完了ダイアログは開かず、「借りられませんでした」を表示する。画面は移動しない                     |

## LoanDetail の返す（`frontend/src/LoanDetail.tsx`）

「返す」を押すと確認なしで返し、返したら完了ダイアログを出す。OK で返却済みの表示に切り替える。

| ID    | 観点 | 条件・入力                                    | 期待する結果                                                                                         |
| ----- | ---- | --------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| CP-12 | 正常 | 貸出中の貸出（id: 5）で「返す」を押す         | 確認ダイアログ（「この本を返しますか？」）は出さず、すぐに `POST /api/loans/5/return` を1回呼ぶ      |
| CP-13 | 正常 | 返す API が返却済みの貸出を返す               | 「本を返しました！」のダイアログが開く。OK を押すまでは、表示は貸出中のまま（「返す」ボタンがある）  |
| CP-14 | 正常 | CP-13 のあと「OK」を押す                      | 「返す」ボタンが消え、返却済みの案内・状態「返却済み」・返した日を表示する                           |
| CP-15 | 正常 | CP-13 のあと、OK を押さずに閉じる（Esc キー） | 返却済みの表示に切り替わる                                                                           |
| CP-16 | 異常 | 返す API が 409（すでに返却済み）を返す       | 完了ダイアログは開かず、「この本はすでに返却済みです」を表示し、取り直した返却済みの表示に切り替える |
| CP-17 | 異常 | 返す API が 500 を返す                        | 完了ダイアログは開かず、「返却できませんでした」を表示する。表示は貸出中のまま                       |
