# テストケース: bookListState（本一覧画面の状態の保持）

- ID の略号: `KS`
- PBI: #32
- 書いた人: Naoki Kanai
- もとにした資料: [画面設計書](../../docs/ap/BookListPage/Screen_design.md)（3章「状態の保持」）

本一覧画面で、検索の文字・開いたまとまり・スクロール位置を、ほかの画面へ移動して戻ってきても残す。
API（`GET /api/books`）の応答は、テストの中で作り物に差し替える。jsdom には画面のスクロールが無いため、
`window.scrollY` と `window.scrollTo` は作り物にする。

## bookListReducer（`frontend/src/state/bookListState.ts`）

本一覧画面の状態を、アクションに合わせて変えた新しい状態を返す。

| ID    | 観点 | 条件・入力                                         | 期待する結果                                                         |
| ----- | ---- | -------------------------------------------------- | -------------------------------------------------------------------- |
| KS-01 | 正常 | 初めの状態に `setKeyword`（「リーダブル」）        | `keyword` が「リーダブル」になる。`expandedKeys` は空のまま          |
| KS-02 | 境界 | 文字が入っている状態に `setKeyword`（空の文字）    | `keyword` が空になる                                                 |
| KS-03 | 正常 | 初めの状態に `toggleExpanded`（key `a`）           | `expandedKeys` が `['a']` になる                                     |
| KS-04 | 状態 | `a` が開いている状態に `toggleExpanded`（key `a`） | `expandedKeys` が空になる（2回で元に戻る）                           |
| KS-05 | 正常 | `a` が開いている状態に `toggleExpanded`（key `b`） | `expandedKeys` が `['a', 'b']` になる                                |
| KS-06 | 状態 | `a` が開いている状態に `setKeyword`                | `expandedKeys` は `['a']` のまま（文字を変えてもまとまりは閉じない） |
| KS-07 | 正常 | 文字と開いたまとまりがある状態に `reset`           | 初めの状態（`keyword` が空、`expandedKeys` が空）になる              |
| KS-08 | 正常 | どのアクションでも                                 | もとの状態のオブジェクト・配列を書き換えず、新しい状態を返す         |

## useBookListState（`frontend/src/state/BookListStateContext.ts`）

`BookListStateProvider`（`frontend/src/state/BookListStateProvider.tsx`）が持つ状態を使う。

| ID    | 観点 | 条件・入力                         | 期待する結果                                                              |
| ----- | ---- | ---------------------------------- | ------------------------------------------------------------------------- |
| KS-09 | 異常 | `BookListStateProvider` の外で呼ぶ | 「BookListStateProvider の中で使ってください」の Error を投げる           |
| KS-10 | 正常 | `BookListStateProvider` の中で呼ぶ | 初めの状態（`keyword` が空、`expandedKeys` が空、スクロール位置 0）を返す |

## BookListPage の状態の保持（`frontend/src/pages/BookListPage.tsx`）

Provider・本一覧画面・本詳細画面と貸出一覧画面の代わりの画面を置き、画面を移動して確かめる。

| ID    | 観点 | 条件・入力                                                                      | 期待する結果                                                                  |
| ----- | ---- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| KS-11 | 正常 | 検索ボックスに文字を入れ、本の行を押して本詳細画面へ移動し、戻る                | 検索ボックスに同じ文字が入っていて、絞り込んだ結果の本だけを表示する          |
| KS-12 | 正常 | まとまりの行を押して開き、置き場所の行を押して本詳細画面へ移動し、戻る          | まとまりの行が開いたまま（`aria-expanded="true"`）で、置き場所の行を表示する  |
| KS-13 | 正常 | 文字を入れ・まとまりを開き、メニューの代わりのリンクで貸出一覧画面を通って戻る  | 文字も開いたまとまりも残っている                                              |
| KS-14 | 正常 | 下へスクロールしてから本詳細画面へ移動し、戻る                                  | 一覧を読み込み終えたあと、離れる前のスクロール位置へ `window.scrollTo` で戻す |
| KS-15 | 状態 | 戻ったあと、一覧の応答がまだ返ってこない                                        | 読み込み中は `window.scrollTo` を呼ばない                                     |
| KS-16 | 状態 | 戻ったあと読み込み中に、ブラウザがスクロール位置を詰めた（scroll イベントで 0） | 覚えた位置は変わらず、読み込み終えたあと離れる前の位置へ戻す                  |
| KS-17 | 状態 | Provider を作り直す（ブラウザで読み込み直したときの代わり）                     | 検索ボックスは空、まとまりは閉じていて、スクロール位置は 0 へ戻す             |
