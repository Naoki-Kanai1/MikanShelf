# テストケース: seedLocations（置き場所を4種類にした初期データと、古い置き場所の書き換え）

- ID の略号: `SL`
- PBI: #29
- 書いた人: kanai-naoki

初期データの置き場所を「横浜 13F 共用」「横浜 14F SD部」「虎ノ門 20F 共用」「新川 777F 共用」の4種類にする。
13F は IT 関連の雑誌（1タイトル1冊、すべて持ち出し禁止）、14F はほとんど貸出可能、虎ノ門・新川は持ち出し禁止と貸出可能が混在する。
古い置き場所の名前（「3階 書架A」など）が残った DB は、起動時に新しい置き場所へ書き換える。
テストはメモリ上の DB（`DB_PATH=:memory:`）を使う。DB を書き換えるテストは、最後に元に戻す（ROLLBACK）。

## migrateOldLocations（`backend/src/db.ts`）

古い置き場所の名前の本を、題名ごとの「n 冊目」に対応する初期データの置き場所・持ち出し禁止に書き換える。

| ID    | 観点 | 条件・入力                                                              | 期待する結果                                                       |
| ----- | ---- | ----------------------------------------------------------------------- | ------------------------------------------------------------------ |
| SL-07 | 正常 | 初期データの本をすべて古い置き場所の名前・貸出可能に戻して呼ぶ          | すべての本が初期データどおりの置き場所・持ち出し禁止になる         |
| SL-08 | 状態 | 初期データで持ち出し禁止になる本が古い置き場所のまま貸出中になっている  | 置き場所だけ書き換わり、持ち出し禁止は変わらない（貸出可能のまま） |
| SL-09 | 境界 | 新しい置き場所の名前になっている本                                      | 置き場所も持ち出し禁止も変わらない（すでに書き換えた本は触らない） |
| SL-10 | 境界 | 2回続けて呼ぶ                                                           | 1回目のあとと、置き場所・持ち出し禁止が同じ                        |
| SL-11 | 境界 | 初期データにない題名の本が古い置き場所の名前のまま                      | そのまま変わらない                                                 |
| SL-12 | 境界 | 「3階 書架A」に似ているが形が違う置き場所（「3階書架A」「13階 書架A」） | 古い名前とみなさず、変わらない                                     |
