# 画面設計書：貸出一覧画面

ログイン中の人が借りた本（貸出中・返却済み）を一覧で見て、貸出の詳細を開くための画面です。

| 項目           | 内容                                                                          |
| -------------- | ----------------------------------------------------------------------------- |
| 画面名         | 貸出一覧                                                                      |
| URL            | `/loans`                                                                      |
| 画面の実装     | `frontend/src/pages/LoanListPage.tsx`、`frontend/src/styles/LoanListPage.css` |
| 使うAPI        | `GET /api/loans`（`backend/src/index.ts`）                                    |
| もとにした資料 | `docs/UI_design.svg`（「貸出一覧」）                                          |

## 1. 画面レイアウト

本一覧画面と同じく、スマホ向けのレイアウトを、どの幅の画面でも使います。

- メニュー（高さ 80px）は画面の下に固定します。「貸出」が選択中になります。
- 画面の名前「借りている本」を左上に置きます。
- 画面の名前の下に、絞り込みのチップ「いま借りている本」「返却済みの本」「すべて」を横に並べます。
- 一覧は枠で囲まず、行を区切り線で分けます。行の左に「題名と借りた日」、右に「状態の印」を置きます。

### だれの貸出を表示するか

ログイン中の人の貸出だけを表示します。ログイン機能はまだ無いため、バックエンドでログイン中の人を「田中」さん（account_id `emp0001`）に固定しています（`CURRENT_USER_ACCOUNT_ID`）。

### レイアウト案にあって、この画面にまだ無いもの

- 「自分の貸出／すべて」の絞り込み
- 予約（「予約中」「まだ借りていません」の行）と、その詳細画面

どちらも別のPBIで作る予定です。

## 2. 画面の項目

| No. | 項目       | 種類   | 表示する内容                               | もとのデータ  |
| --- | ---------- | ------ | ------------------------------------------ | ------------- |
| 1   | メニュー   | リンク | 本／貸出／蔵書リクエスト。「貸出」が選択中 | －            |
| 2   | 画面の名前 | 見出し | 「借りている本」                           | －            |
| 2-1 | 絞り込み   | チップ | いま借りている本／返却済みの本／すべて（1つ選ぶ） | －            |
| 3   | 題名       | 文字   | 本の題名。長いときは折り返す               | `title`       |
| 4   | 借りた日   | 文字   | 「借りた日 2026年11月2日」の形（日本時間） | `borrowed_at` |
| 5   | 状態の印   | 印     | 「貸出中」または「返却済み」               | `status`      |

### 絞り込みのチップ

| チップ       | 表示する貸出               |
| ------------ | -------------------------- |
| いま借りている本 | `status` が `borrowed`     |
| 返却済みの本 | `status` が `returned`     |
| すべて       | すべて                     |

- 画面を開いたときは「いま借りている本」を選んだ状態です。
- 選んでいるチップは、背景 secondaryContainer で、チェックの印がつきます。選んでいないチップは背景なし、枠 outlineVariant です。
- 絞り込みは画面の中だけで行います（APIは全件を返します）。

一覧の並びは、貸出中を先に、その中は借りた日が新しい順です。

### 状態の印の見た目

| 表示     | 条件                   | 見た目                                                     |
| -------- | ---------------------- | ---------------------------------------------------------- |
| 貸出中   | `status` が `borrowed` | 持ち出しの印つき。背景 surfaceContainerHighest、枠 outline |
| 返却済み | `status` が `returned` | チェックの印つき。背景なし、枠 outline                     |

印は `frontend/src/components/LoanStatusChip.tsx` で、貸出詳細画面と共通です。

## 3. 操作

| 操作                 | 動き                                                                         |
| -------------------- | ---------------------------------------------------------------------------- |
| 貸出の行を押す       | その貸出の貸出詳細画面（`/loans/:loanId`）へ移動する。行のどこを押してもよい |
| 絞り込みのチップを押す | そのチップを選び、一覧をその条件で表示し直す                               |
| メニューの項目を押す | その画面へ移動する                                                           |

## 4. 読み込み中・エラー・0件

| 状態       | 表示                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 読み込み中 | 「読み込み中…」                                                              |
| エラー     | 「貸出の一覧を読み込めませんでした。時間をおいて、もう一度開いてください。」 |
| 0件        | 「いま借りている本」:「いま借りている本はありません。」／「返却済みの本」:「返却済みの本はまだありません。」／「すべて」:「借りた本はまだありません。」 |
