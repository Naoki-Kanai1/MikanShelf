# 画面のレイアウトと部品の決まり（レスポンシブデザイン）

画面の幅に合わせて、どの見た目にするかの決まりです。Material Design 3 の「ウィンドウサイズクラス」の 5 つの区分に合わせています。
もとにした画面は `docs/UI_design.svg` のスマホの画面（幅 390px）と「PC：」の画面（幅 1280px）で、この 2 つの幅では原案と同じ見た目になるようにしています。

## 1. 区分

| 区分        | 画面の幅     | 主な端末                                   | 原案との関係                     |
| ----------- | ------------ | ------------------------------------------ | -------------------------------- |
| Compact     | 〜599px      | スマホ（縦・横）                           | スマホの画面（390px）            |
| Medium      | 600〜839px   | タブレットの縦、折りたたみ端末を開いたとき | スマホと PC の間（原案なし）     |
| Expanded    | 840〜1199px  | タブレットの横、小さめの PC の画面         | 「PC：」の画面を狭い幅に合わせる |
| Large       | 1200〜1599px | PC                                         | 「PC：」の画面（1280px）         |
| Extra-large | 1600px〜     | 大きな PC の画面                           | 「PC：」の画面を広い幅に合わせる |

「←」は左の区分と同じ、という意味です。

## 3. 部品の決まり（どの区分でも同じにするもの）

区分によって変えるのは、**メニューの種類・左右の余白・一覧の形・メインのボタンの横幅**だけです。それ以外の部品は、どの区分でも同じ大きさ・同じ置き方にして、画面の幅が変わっても同じアプリに見えるようにします。

| 部品                           | 決まり                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 一覧の行                       | 行と行の間に区切り線（outlineVariant の 1px）を引く。枠で囲むときは枠の内側に引く。行の上下の余白は 12px。押せる行は、マウスを乗せると背景の色が変わる。貸出一覧の表の形（Expanded 以上）では、状態の印の列の幅を決まった値にせず、いちばん幅の広い印に合わせる（subgrid で全ての行が列を共有する）。印の文字が変わっても見切れず、どの行の印も同じ幅になる |
| 一覧を囲む枠（Medium 以上）    | 線は outlineVariant の 1px、角の丸みは 12px、幅は最大 720px                                                                                                                                                                                                                                                                                                 |
| 情報のカード（詳細画面）       | 線は 1px、角の丸みは 12px。行の高さは 68px 以上、上下の余白は 12px、左右の余白は 16px（置き場所などが2行以上になっても、区切り線と文字の間があく）。行と行の間に区切り線を引く（一覧の行と同じ）                                                                                                                                                            |
| 詳細画面の中身の幅             | 題名・情報のカード・ボタン・案内は、最大 560px（本詳細と貸出詳細で同じ）                                                                                                                                                                                                                                                                                    |
| メインのボタン（借りる・返す） | 塗りつぶしのボタン。高さ 48px、角は丸く（24px）、文字は 14px。情報のカードの 24px 下に、カードと同じ幅で置く（どの区分でも同じ）                                                                                                                                                                                                                            |
| 返却済みなどの案内             | メインのボタンと同じ位置（情報のカードの 24px 下）に置く                                                                                                                                                                                                                                                                                                    |
| ダイアログ                     | 幅は最大 312px、角の丸みは 28px、内側の余白は 24px。完了のダイアログのボタンは、押しやすいよう横幅いっぱいにして文字を真ん中に置く（高さ 48px）                                                                                                                                                                                                             |
| 絞り込みのチップ               | 高さ 32px、角の丸みは 8px（Material Design 3 の filter chip）                                                                                                                                                                                                                                                                                               |
| 戻るボタン                     | アイコンだけのボタン。押せる範囲は 40px                                                                                                                                                                                                                                                                                                                     |

色は、本詳細・貸出詳細画面（`BookDetail.css`）とほかの画面（`theme.css`）で、まだ別々の変数を使っています。色をそろえるときは、この表の部品ごとに変数を一本化します。

## 4. 決めた理由

- **区分の幅**: Material Design 3 の区分（600 / 840 / 1200 / 1600px）をそのまま使います。独自の幅にしないことで、端末が増えても判断が変わりません。
- **Compact で幅いっぱいにする**: 以前は幅 480px で中央に置いていましたが、M3 の Compact は画面いっぱいに使うのが基本です。390px の原案の見た目は変わりません。
- **Medium で左のメニューにする**: M3 では、Medium 以上は navigation rail を使います。下のメニューのままだと、横に広がりすぎて押しにくくなります。
- **Medium の一覧を枠で囲む**: 幅が広くなっても、表の列（置き場所など）を足すほどの余裕はありません。行の形はスマホと同じにして、PC と同じ枠で囲み、見た目を PC に近づけます。
- **部品の大きさをどの区分でも同じにする**: 画面の幅で部品の大きさや線が変わると、別のアプリのように見えます。情報のカードの行の高さ（68px）やボタンの高さ（48px）は原案のとおりにし、どの区分でも同じにします。区切り線は、行の境目が分かりやすいよう、一覧にも情報のカードにも引くことにそろえます。
- **ボタンをカードと同じ幅にする**: ボタンの幅を画面の幅で変えず、すぐ上のカードの幅にそろえます。広い画面でボタンが長くなりすぎないよう、詳細画面の中身の幅を 560px までに抑えます（M3 のダイアログの最大の幅と同じ）。
- **Extra-large で縦メニューを広げる**: 幅に余裕があるので、M3 の expanded navigation rail にして名前をアイコンの横に並べ、見つけやすくします。1280px の原案のメニューは変わりません。
- **中身を左に寄せ、幅を抑える**: 原案の PC の画面と同じく、中身は左に寄せます。原案では一覧の幅は 960px でしたが、題名の列だけが長くなり、題名と置き場所・状態の印が離れて見えるため、720px までに狭めます（置き場所と状態の印の列の幅は変えず、題名の列が短くなります）。詳細画面は 560px までです。

## 5. 実装

| ファイル                                              | 内容                                                                    |
| ----------------------------------------------------- | ----------------------------------------------------------------------- |
| `frontend/src/components/AppShell.css`                | 区分ごとのメニューの切り替えと、左右の余白などの変数                    |
| `frontend/src/components/NavigationBar.tsx` / `.css`  | 下のメニュー（Compact）                                                 |
| `frontend/src/components/NavigationRail.tsx` / `.css` | 左のメニュー（Medium 以上。Extra-large で広げる）                       |
| `frontend/src/components/navItems.tsx`                | メニューの項目。2 つのメニューで共通                                    |
| 各画面の CSS                                          | `@media (min-width: 600px)` と `@media (min-width: 840px)` で切り替える |

CSS の変数は `@media` の幅に使えないため、各画面の CSS では幅を数字で書きます。新しい画面を作るときも、この表の区分と幅に合わせてください。

## 6. 決まっていないこと

- **Expanded 以上で、一覧と詳細を横に並べるか。** M3 には、一覧と詳細を 2 列に並べる形（list-detail）があります。原案は 1 列なので、今回は入れていません。
- **蔵書リクエストの画面。** まだ画面がないため、この決まりに合わせて作ります。
